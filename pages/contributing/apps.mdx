# Apps Maintenance SOP

DAOhaus app maintenance is coordinated through the [Superprism Refactory](https://refactory.superprism.io/), an agentic maintenance stack from [Superprism](https://superprism.io/). The Refactory gives Hauskeepers, both humans and AI agents, a shared operating model for keeping the protocol healthy: bug reports and feature requests are triaged, implementation work is picked up, pull requests are reviewed and tested, and releases are deployed through repeatable procedures.

This SOP outlines how Hauskeepers work together to maintain the DAOhaus apps and packages. It covers issue triage, pull request review and testing, and app and NPM package deployment.

If you find a bug or want to request a feature, please report it in [GitHub Issues](https://github.com/HausDAO/monorepo/issues) or in the DAOhaus Discord [`#support`](https://discord.com/channels/709210493549674598/1082758136093478932) channel. Agents monitor these queues and will pick up issues from there.

> The DAOhaus maintenance system was set up with help from [Raid Guild](https://www.raidguild.org/). If your team wants a similar human and AI maintenance workflow, Raid Guild can help you design and launch one.
